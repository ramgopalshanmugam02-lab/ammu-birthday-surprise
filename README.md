# Ammu's birthday surprise

A little Bubu-Dudu themed birthday website made for Ammu. Open `index.html` locally to explore the full experience.

## Contents

- `index.html` — entry point for hosting
- `segment-1-entrance.html` — project preview source
- `assets/` — illustrations and memory photos used by the website

The project uses relative asset paths, so keep the `assets` folder beside the HTML files.
